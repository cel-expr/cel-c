# CEL C

C implementation of the [Common Expression Language](http://cel.dev).

## API/ABI Stability

CEL C makes use of [protobuf/upb](https://github.com/protocolbuffers/protobuf/tree/main/upb),
which itself provides no API/ABI stability guarantees. As such, CEL C also has
**no stability guarantees** with respect to its API/ABI.
